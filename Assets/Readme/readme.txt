	Техническое описание
- Запуск проекта через EntryPoint, который инициализирует кор проекта. UI проекта основан на MVC.
- EventBus - статик обработчик событий в мире. 
- TaskManager - отвечает за порядок запуска сценариев, обработка групп шагов. Слушает EventBus на события. Обращается к контроллеру GameView для обновления данных UI.
- TasksLogger - получает обновления статусов задач. Хранит логи задач только в свой сессии.
- ResultAnalyzer - реализует подсчет баллов и штрафов на основе данных лога. Получает настройки анализа из SO. Может делать перерасчет последнего лога на основе другой настройки анализа.
